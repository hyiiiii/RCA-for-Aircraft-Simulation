# 首次调姿后 → 前对合：当前 CAD 的完整数值例子

代码使用固定对应的 A1–A3、B1–B3，做两步刚体最小二乘配准。先从 B 的观测估计基准，再构造 A 的动态对接目标，最后求 A 的运动。不会把 A、B 六个点作为一个整体共同移动。

## 坐标约定和求解

q_Ai、q_Bi 是固定局部坐标，y_Ai、y_Bi 是首次调姿完成后测到的世界坐标。分别求：

```
min Σ ||R_A q_Ai + t_A − y_Ai||²
min Σ ||R_B q_Bi + t_B − y_Bi||²
```

RᵀR=I，det(R)=1。都使用 Kabsch/SVD 得到估计位姿 T_A、T_B。

当前默认 CAD 中，机身局部原点在最终世界原点，机头局部原点在最终 x=-900 mm；因此理想装配关系 D_BA 的旋转为 I，平移 d_BA=(-900,0,0) mm。首次调姿后机头还保留 250 mm 间隙。

机头本次对合要去的目标是：

```
T_A,dock = T_B,estimated D_BA
y_Ai,dock = R_B (q_Ai+d_BA) + t_B
```

再解：

```
min Σ ||ΔR_A y_Ai + Δt_A − y_Ai,dock||²
```

等价于：

```
H_A = T_B,estimated D_BA inverse(T_A,estimated)
ΔR_A = R_B R_Aᵀ
Δt_A = t_B + R_B d_BA − ΔR_A t_A
```

因此 B 的测量会改变 R_B/t_B，进而改变 A 的目标点和最终配准结果。B 自身不执行运动；C 也不动。

## 教学工况

沿用程序默认尺寸和真实 CAD checkpoint。假设首次调姿后：

- A：R_A=I，t_A=(-1150,0,0) mm。
- B：绕世界 Z 轴转了 +1°，t_B=(0,2,0) mm。
- C：R_C=I，t_C=(1150,0,0) mm。

这是为了展示机身影响而放大的教学偏差，不代表默认噪声大小。此例不加观测噪声，也不加本次前对合工艺误差，便于把几何关系算清楚。

A 的局部 checkpoint：

```
A1 = ( 150,  272.956040,   99.347874)
A2 = (   0, -199.024184,  167.001120)
A3 = (-150,  -34.457242, -195.416730)
```

机身旋转矩阵与位移：

```
R_B = [[0.999847695, -0.017452406, 0],
       [0.017452406,  0.999847695, 0],
       [0,            0,           1]]
t_B = (0,2,0)
```

拟合求得的机头运动：

```
ΔR_A = R_B
Δt_A = t_B + R_B (-900,0,0) − R_B (-1150,0,0)
     = t_B + R_B (250,0,0)
     = (249.961924, 6.363102, 0) mm
```

机头原点的新位置为 (-899.862926,-13.707166,0) mm。注意 Δt 是变换公式中的平移项，不是机头原点新旧坐标直接相减；原点也要先乘 ΔR。

## 九个世界坐标的变化

单位 mm，数值四舍五入到小数点后六位。

| 点 | 首次调姿后 | 前对合后 |
|---|---|---|
| A1 | (-1000.000000, 272.956040, 99.347874) | (-754.649511, 261.825163, 99.347874) |
| A2 | (-1150.000000, -199.024184, 167.001120) | (-896.389475, -212.701038, 167.001120) |
| A3 | (-1300.000000, -34.457242, -195.416730) | (-1049.238718, -50.777021, -195.416730) |
| B1 | (-304.874278, 278.629128, 102.606043) | 同左 |
| B2 | (4.010796, -227.778331, 192.836283) | 同左 |
| B3 | (300.863482, -44.850797, -295.442326) | 同左 |
| C1 | (1000.000000, 281.907786, 102.606043) | 同左 |
| C2 | (1150.000000, -229.813333, 192.836283) | 同左 |
| C3 | (1300.000000, -52.094453, -295.442326) | 同左 |

以 A1 为例：

```
p_A1,new = ΔR_A (-1000,272.956040,99.347874) + Δt_A
         = (-754.649511,261.825163,99.347874)
```

如果 B 没有偏差，R_B=I、t_B=0，则立即退化为 ΔR_A=I、Δt_A=(250,0,0)。这直接显示了 B 对结果的影响。

实际仿真会在 H_cmd 后加入 E：H_real=E H_cmd，然后更新真实状态，再加新观测噪声。实际位置不必等于上述指令目的位置。固定世界设计目标也不会被动态对接目标覆盖，后者负责接到当前 B，前者仍用于评价偏差。
