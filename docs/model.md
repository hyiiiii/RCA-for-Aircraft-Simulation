# 四阶段坐标反馈仿真模型

> 本文记录 `generation_mode=feedback` 的原示意点几何。默认的 FreeCAD 逆向生成模式见 [cad_generation.md](cad_generation.md)：阶段 1 的固定目标已与最终方向和中心线对齐，仅保留接口间隙；局部参考改为完整 CAD 表面点，后对合与再调姿理想目标相同；本文的误差递推和反馈结构继续适用。

本项目使用**预先指定结构方程的仿真模型**生成数据，再利用各阶段坐标检测和定位新增异常。因果图来自下面的定位规则，项目不执行因果发现，也不把坐标相关性直接认定为因果关系。

## 1. 固定什么，随机生成什么

三个部件分别为 A（机头）、B（机身）、C（机尾），每个部件有三个带身份标记的非共线点。点的顺序始终为 `A1,A2,A3,B1,B2,B3,C1,C2,C3`，单位均为 mm。

每个部件的局部参考点固定为：

\[
q_1=(-100,-40,0),\quad q_2=(100,-40,0),\quad q_3=(100,40,0).
\]

这组示例几何只用于验证方法，不代表实际飞机尺寸。参考点只定义一次，不在各阶段或各条轨迹中重新抽样。正常目标和相对姿态也固定；每一步的**实际移动量由当时的观测坐标计算**，因此不是固定的九条独立传递链。

| 参数 | A | B | C |
|---|---|---|---|
| 初始平移 | \((-750,50,10)\) | \((0,0,0)\) | \((750,-50,-10)\) |
| 首次调姿的目标平移 | \((-650,20,0)\) | \((0,0,0)\) | \((650,-20,0)\) |
| 正常组装完成的平移 | \((-500,0,0)\) | \((0,0,0)\) | \((500,0,0)\) |

以上正常参考姿态均无旋转。最后整机的固定目标由正常组装结果绕全局 Z 轴旋转 90°，再平移 \((10,20,30)\) 得到。这描述的是目标，实际执行的最终动作仍需拟合当前观测。

程序接口 `model_spec()` 返回可直接写入 JSON 的模型说明，包括：

- `reference_points`：带点名的局部参考坐标；
- `initial_positions`：初始全局坐标；
- `target_coordinates`：各阶段无误差情况下的正常坐标；
- `target_relative_poses`：固定的 \(D_{BA}\)、\(D_{BC}\)；
- `stage_rules`、`parameter_meaning`：动作规则和变量约定。

其中前、后对合的实际目标由当时 B 的估计姿态确定，不一定等于 `target_coordinates` 中的无误差坐标。

## 2. 坐标、姿态与动作节点

阶段编号为 \(k=0\) 初始、\(1\) 首次调姿、\(2\) 前对合、\(3\) 后对合、\(4\) 再调姿。

\(X_{bi,k}\in\mathbb R^3\) 表示点的真实坐标，\(Y_{bi,k}\in\mathbb R^3\) 表示测得的坐标。姿态和动作都用刚体变换表示：

\[
H=\begin{bmatrix}R&t\\0&1\end{bmatrix},\qquad
R^\mathsf TR=I,\quad\det R=1,\quad t\in\mathbb R^3.
\]

\(H\) 有六个自由度（旋转三维、平移三维）。代码用一个 \(3\times3\) 旋转矩阵与一个三维向量存储，作用约定为 \(x'=Rx+t\)。

**图中坐标节点和动作节点可以有不同类型、不同维度。** 坐标节点表示三维位置，动作节点表示整组点共享的一次刚体运动。每个节点都由明确的结构方程定义；没有要求全部节点必须是同一类变量。

定义刚体配准算子：

\[
\operatorname{Fit}(S,T)
=\underset{R\in SO(3),\,t\in\mathbb R^3}{\arg\min}
\sum_i\|Rs_i+t-t_i^{\rm target}\|^2.
\]

代码 `rigid_fit(source, target)` 使用 SVD 求解，要求两组点对应且非共线，不允许反射。由局部模板拟合部件当前姿态：

\[
G_b(Y_{b,k})=\operatorname{Fit}(\{q_{bi}\},\{Y_{bi,k}\}).
\]

这里 \(G_b\) 把局部坐标变到全局坐标；\(H\) 则是即将执行的增量动作，两者不能混淆。

## 3. 四阶段的结构方程

### 首次调姿：每个部件独立定位

设 \(T_b^{(1)}\) 是表中的固定调姿目标点集：

\[
H_{b,1}=\operatorname{Fit}(Y_{b,0},T_b^{(1)}),\qquad b\in\{A,B,C\}.
\]

一个部件的三个观测点共同决定该部件动作，该动作影响这个部件的所有点。

### 前对合：B 固定，移动 A

用首次调姿后的观测分别拟合 \(G_A\)、\(G_B\)。固定正常相对姿态为

\[
D_{BA}=\begin{bmatrix}I&(-500,0,0)^\mathsf T\\0&1\end{bmatrix}.
\]

它表示 A 的目标坐标系在 B 局部坐标系中的姿态。执行：

\[
\boxed{H_{A,2}=G_BD_{BA}G_A^{-1}},\qquad
H_{B,2}=H_{C,2}=I_4.
\]

因此六个点 \(A1,A2,A3,B1,B2,B3\) 共同影响前对合动作，动作再作用于 A 的各点。此处没有将 A、B 的不同物理测点强行拟合为相互重合。

### 后对合：已连接的 AB 固定，移动 C

根据前对合后的 B、C 观测拟合 \(G_B\)、\(G_C\)，规定：

\[
D_{BC}=\begin{bmatrix}I&(500,0,0)^\mathsf T\\0&1\end{bmatrix}.
\]

\[
\boxed{H_{C,3}=G_BD_{BC}G_C^{-1}},\qquad
H_{A,3}=H_{B,3}=I_4.
\]

AB 在这一步没有定位运动；局部过程扰动仍按统一生成规则添加。

### 再调姿：整机共享一个动作

设 \(T^{(4)}\) 是固定的最终目标点集：

\[
\boxed{H_4=\operatorname{Fit}(\{Y_{i,3}\}_{i=1}^{9},T^{(4)})},\qquad
H_{A,4}=H_{B,4}=H_{C,4}=H_4.
\]

此处使用全部九个点。任一参与定位的点偏移，都可能改变拟合动作，进而影响其他部件的终检点。连接后的部件执行相同刚体变换，不独立随机运动。

## 4. 每一步的真实状态与观测生成

每步先用上一阶段观测算动作，再把动作应用于上一阶段真实坐标：

\[
\boxed{
X_{bi,k}=R_{b,k}(Y_{k-1})X_{bi,k-1}
+t_{b,k}(Y_{k-1})+U_{bi,k}+F_{bi,k}
}
\]

\[
\boxed{Y_{bi,k}=X_{bi,k}+\varepsilon_{bi,k}}.
\]

各轴独立的小扰动 \(U\) 默认标准差为 0.02 mm，测量噪声 \(\varepsilon\) 默认标准差为 0.03 mm。初始真实坐标固定，初始观测也有测量噪声。

`Fault(stage, point, offset)` 只在指定阶段的**动作完成之后、观测之前**给指定点加入一次偏移；`offset` 为该阶段**全局 XYZ 坐标系**中的向量。误差随后由状态递推保留，并可经定位反馈影响其他点，不重复注入。所有随机噪声在递推前采样，同一配置和 seed 下的健康/故障轨迹共享完全相同的外生噪声。

测量噪声不会直接加进下一阶段真实坐标，但它可以改变控制器计算的动作，从而间接改变下一阶段真实位置。这条反馈路径是模型的重要组成部分。

刚体动作本身保持点间距离；新增局部扰动和局部故障允许改变距离。因此本模型是“刚体定位运动加局部偏差”，并未同时强制所有点间距离恒定。

## 5. 质量判定与仅用观测的溯源

无误差目标由 `nominal_trajectory()` 给出。最终质量标签定义为：

\[
Q=\mathbf1\!\left[\max_i\|Y_{i,4}-X^\star_{i,4}\|>\tau\right],
\qquad\tau=1\text{ mm（默认）}.
\]

`quality_limit` 只影响质量判断，不改变数据生成。**发生故障注入与最终超限是两种标签**：定位反馈可能补偿、放大或重新分配偏差，不能用注入幅度直接代替最终误差。

诊断输入只使用 `observed`。`predict_next(Y_previous, stage)` 根据指定规则重新计算动作，再预测下一次坐标；新增偏差分数来自：

\[
r_{i,k}=Y_{i,k}-\operatorname{predict\_next}(Y_{k-1},k)_i.
\]

当测量噪声为零且规则正确时，这个残差等于本步的 \(U_{i,k}+F_{i,k}\)，不会把已经解释的反馈传播再次当成新增故障。有测量噪声时：

\[
r_{i,k}=U_{i,k}+F_{i,k}+\varepsilon_{i,k}
-R_{b,k}(Y_{k-1})\varepsilon_{i,k-1}.
\]

因此实际异常阈值要用独立健康轨迹校准；健康校准的统计阈值与最终工程公差 \(\tau\) 各有用途。`true`、注入标签和模拟器保存的实际动作仅用于验证，不作为诊断输入。

## 6. 可复现的跨点传播例子

在项目目录执行下面的代码，关闭随机噪声，在后对合完成时给 C1 注入全局 \((0,1.2,0)\) mm：

```python
import numpy as np
from assembly_sim.model import Fault, ModelConfig, POINT_NAMES, simulate

config = ModelConfig(process_sigma=0, measurement_sigma=0, quality_limit=1)
healthy = simulate(config, seed=42)
faulty = simulate(config, seed=42, fault=Fault(3, "C1", (0, 1.2, 0)))

b2 = POINT_NAMES.index("B2")
delta = faulty.observed[4, b2] - healthy.observed[4, b2]
final_errors = np.linalg.norm(faulty.observed[4] - faulty.nominal[4], axis=1)
print("终检 B2 的配对偏移：", delta)
print("B2 偏移模长：", np.linalg.norm(delta))
print("全体终检点最大误差：", final_errors.max())
print("是否超过质量限度：", final_errors.max() > config.quality_limit)
```

结果约为：B2 偏移 \((0.151749,-0.007406,0)\) mm，模长 0.151930 mm。C1 通过改变整机再调姿动作影响了 B2，实际生成方程中存在这条路径。全体终检点最大误差约 0.965402 mm，因此虽然注入了 1.2 mm 的故障，最终仍未超过 1 mm 限度。

## 7. 使用真实坐标数据的边界

实际数据需要稳定的点身份、阶段顺序和统一坐标基准，还需要正常几何/已确认合格的参考流程，以及哪些点参与定位、哪些部件移动或固定等工艺信息。尤其要确认 checkpoint 是否真正参与动作计算；若仅用于事后检测，就不能把该坐标直接画成控制动作的原因。

这套指定的结构方程能验证“具体阶段、具体测点”的定位方法，但不意味着任意真实系统都采用这些控制规则，也不保证仅凭一次终检可以唯一确定故障源。真实部署需要先核对或标定定位规则，再使用独立健康数据校准诊断。
