# CAD 固定目标与正向数据生成（cad_forward）

新版默认只用一条正向链路。CAD 定义几何和目标，不进行逆向随机生成。生成入口只保留当前 CAD 正向方式。

## 坐标和目标

世界坐标系 W 是固定的外部右手基准。默认最终机身中心与 W 原点重合，默认 X 指向机尾。A/B/C 的局部原点分别取三段主体的轴向中点；修改最终 B 位姿时，W 不动，三个局部坐标系一起改变世界位置和方向。默认原点分别为 (-900,0,0)、(0,0,0)、(900,0,0) mm；机尾原点不按包含尾翼和出气筒的质量中心计算。

每段三个不共线的 checkpoint 固定在 CAD 表面，局部坐标 `q_bi` 永久不变。`T_Wb` 表示局部到世界的位姿：

```
p_Wbi = R_Wb @ q_bi + t_Wb
```

目标只定义阶段 1–4。阶段 0 是每条样本独立随机生成的初始工况，没有“完美初始目标”。

| 状态 | A 目标 | B 目标 | C 目标 | 执行部件 |
|---|---|---|---|---|
| 0 初始 | 随机初态 | 随机初态 | 随机初态 | — |
| 1 首次调姿 | 最终位置沿 -X 退让前间隙 | 最终位置 | 最终位置沿 +X 退让后间隙 | A/B/C 独立 |
| 2 前对合后 | 最终位置 | 不变 | 保留后间隙 | A |
| 3 后对合后 | 最终位置 | 最终位置 | 最终位置 | C |
| 4 再调姿后 | 最终位置 | 最终位置 | 最终位置 | ABC 共用一次运动 |

默认设置下阶段 1–4 的理想旋转全为单位阵。设置最终 B 的旋转后，各段共享该目标旋转；阶段 3、4 目标完全一致，**理想增量**为 R=I、t=0；各段的**绝对平移**仍由局部原点决定，不能误认为三个绝对位姿都是单位矩阵。

## 每条轨迹的正向过程

1. 从阶段 1 目标原点出发，每段独立采样世界轴向平移偏移（逐轴均匀分布），独立采样单位轴及有界旋转角。初态随机性独立于工艺误差。
2. 根据真实初态和局部 checkpoint 生成真实世界坐标，再加观测噪声。
3. 读取上一阶段观测值，通过带正行列式约束的刚体配准估计当前位姿。首次调姿计算 `H_cmd = T_target @ inverse(T_estimated)`。前、后对合改为 `H_cmd = T_B_est @ D_Bm @ inverse(T_m_est)`：D_Bm 是 CAD 中机头或机尾相对机身的固定装配关系。
4. 对活动部件采样小 SE(3) 误差 E，执行 `H_real = E @ H_cmd`，更新 `T_true_next = H_real @ T_true_previous`。未活动部件的 H_cmd、E、H_real 均为单位阵。
5. 由局部 checkpoint 和新真实位姿重新生成世界坐标，再添加观测误差。观测值用于下一阶段反馈，绝不直接写回真实状态。
6. 阶段 4 将全部配置的观测点共同拟合到最终目标，三个部件共享同一个 H_cmd、E 和 H_real。无需也不会在“理想最终状态之前”另造一次随机扰动。

前后对合使用**观测到的机身 B 作为对接基准**。A 的运动取决于 A、B 的观测；C 的运动取决于 B、C 的观测。B 在这两步保持不动。公开的阶段设计目标仍固定，用于理想展示和质量评价；实际对合指令的目的位置跟随估计的 B 位姿。新版 metadata 标记 `controller_policy=body_relative`，旧版未标记文件按原固定世界位置控制解读，避免对旧数据换用错误的诊断方程。

## 三种随机量

| 类型 | 参数 | 分布 / 作用 |
|---|---|---|
| 初始摆放平移 | `forward_settings.initial_translation_mm`，默认 350 | 每段每个世界轴均匀 [-上限,+上限] mm，中心为阶段 1 目标原点 |
| 初始摆放旋转 | `forward_settings.initial_rotation_deg`，默认 25 | 均匀随机轴，角度均匀 [-上限,+上限]；不是 SO(3) 上的均匀分布 |
| 工艺平移误差 | `process_sigma`，默认 0.02 | 每次活动刚体、每个世界轴的高斯标准差，mm |
| 工艺旋转误差 | `forward_settings.process_rotation_deg`，默认 0.002 | 旋转向量每轴高斯标准差，deg；Rodrigues 生成合法旋转 |
| 观测误差 | `measurement_sigma`，默认 0.03 | 每阶段每个测点每轴独立高斯噪声，mm |

E 左乘且用世界坐标表达，旋转绕 W 原点，因此点的位置误差随离原点距离而变大。角度参数是旋转向量各轴标准差，不是总角度上限。三个随机流（初态、工艺、观测）分开，并记录全局 seed 与配置，修改工艺误差或注入故障时仍可做相同初态/观测噪声的配对实验。

异常样本额外向活动部件 E 注入模长 `fault_magnitude` 的随机方向平移。`fault_stage` 选择阶段；`fault_part` 严格限定注入部件，合法组合为阶段 1=A/B/C、2=A、3=C、4=ABC。指定不相容组合报错；随机阶段只从与指定部件相容的阶段中采样。异常作用于整段，根因标签为 `h1_A/B/C`、`h2_front`、`h3_rear`、`h4_final`，不再标记成某个单独 checkpoint 的位置故障。

## 通用数据划分

总数量 n_total 和测试占比 test_fraction 决定 train/test 两个集合。整条轨迹划分，初态、工艺误差和观测误差使用相同规则，两个集合都可能包含正常和故障轨迹。不生成 calibration，不替特定算法挑选健康训练样本。

故障总数是 round(n_total*fault_fraction)，测试数量是 floor(n_total*test_fraction+0.5)。故障选择与集合划分使用独立随机流，因此各集合故障比例会有统计波动。改变测试占比不会改变同一 source_id 的物理数据。

生成器不运行溯源。控制器只使用观测；真值与动作保存在 evaluation/，标签在 labels.json。健康误差参考与阈值校准属于具体算法实验。独立溯源入口默认依据训练标签选择正常流程，在算法内部拆分用于估计和定阈值，界面不提供健康参考输入。测试标签不用于预测。

## R、t 的数学来源

刚体位姿是局部坐标到世界坐标的变换 p=Rq+t。只有 R 的三个旋转自由度和 t 的三个平移自由度；R 满足 RᵀR=I、det(R)=1，不能把九个元素任意独立采样。

观测拟合和运动配准使用 SVD/Kabsch：给定对应点 x_i、y_i，最小化 Σ||R x_i+t−y_i||²，约束 R 为合法旋转。

1. 分别计算两组点的中心 x̄、ȳ，减去中心得到 X、Y（每行一个点）。
2. 对 C=XᵀY 做 SVD，C=UΣVᵀ。
3. R=V diag(1,1,det(VUᵀ)) Uᵀ，t=ȳ−R x̄。反射修正保证 det(R)=+1。

估计当前位姿时 x 是 CAD 局部点，y 是当前观测点。首次调姿求 H_cmd=T_target inverse(T_est)。对合求 H_cmd=T_B_est D_Bm inverse(T_m_est)，其中 D_Bm=inverse(T_B_final)T_m_final。最后用全部配置的当前观测点拟合最终设计点，得到共享整机动作。

H_real=E H_cmd，T_next_true=H_real T_previous_true。初态 R/t 和 E 是按配置随机采样的合法刚体变换；控制指令不是随意随机选的。显示的阶段实际来自真实状态传播，阶段目标来自预先定义，仅观测拟合是从噪声坐标估计。

## 适用范围

最终整机刚体调姿能降低整体误差，但保持整机所有点间的相对距离，因此不能消除 A/B/C 内部相对装配误差。这种残差应保留，不能为了让最终结果完美而重置真实位姿。

当前是阶段端点的运动学仿真，未求解接触、夹具力学、形变或碰撞约束。初态随机不保证实体互不穿插；前端阶段间插值是播放辅助，不是有动力学意义的连续采样轨迹。

## 自定义最终 B 位姿

`cad_motion` 中的 `final_x_mm / final_y_mm / final_z_mm` 是最终机身局部原点在 W 中的位置；`final_roll_deg / final_pitch_deg / final_yaw_deg` 分别为绕 X/Y/Z 的角度，按 `R=Rz(yaw) Ry(pitch) Rx(roll)` 组成旋转。令最终 B 位姿为 G，则新目标为 `T*[k,b] = G T*default[k,b]`。前、后间隙沿 `G.R[:,0]` 设置，不固定沿世界 X。

CAD 局部 checkpoint 和刚体形状保持原定义；FreeCAD 装配导出、世界 checkpoint、目标文件和模型预览均采用同一个 G。无初始旋转扰动时，初态方向等于当前目标方向；有扰动时按 `R_initial = R_random R_target` 生成。前、后对合继续跟随当前观测 B，固定相对装配关系不变。最后的理想动作仍为单位增量。
