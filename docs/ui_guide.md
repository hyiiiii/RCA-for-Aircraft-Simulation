# 通用生成器：参数、位姿和故障

## 数量和划分

只输入总流程数和测试占比。例如 1000 条、测试占比 0.2，就生成训练 800 条、测试 200 条。一条流程含五个状态；若三段共有 P 个 checkpoint，就有 5×P 个三维观测记录。默认 P=9，即每条 45 行；增删测点会改变行数，不改变流程数。

训练/测试只是完整流程的随机分组，两者都可包含正常与故障样本。没有“健康训练”或“健康校准”分类；生成器不运行任何训练、校准或溯源算法。健康校准是上一版算法用于定异常分数阈值的方法，不是数据的必需部分。

测试数按总数×占比四舍五入（半向上），剩余为训练，要求两个集合非空。故障总数按 round(总数×故障比例) 选择。划分与故障选择独立，所以各集合故障比例可有波动。

## 位姿与显示

CAD 固定了零件形状和点的局部坐标 q；位姿决定它在世界中的位置、方向：p=Rq+t。

- 阶段实际：执行动作与工艺误差之后的仿真真实位姿；不是由带噪声观测推算的估计。
- 观测拟合：通过测到的几个点，估计零件此刻的 R、t。
- 阶段目标：事先规定的理想位姿，也不是估计。

刚体形状已经确定时，一个 R 和一个 t 就能描述位姿。R 是 3×3 合法旋转矩阵（仅三个旋转自由度），t 是三维平移。点的世界坐标可全部由它们计算。位姿不能描述形变或尺寸变化。

观测拟合和运动计算使用 Kabsch/SVD 最小二乘刚体配准：找到使对应测点整体距离最小的合法旋转和平移。具体公式见 simulation_workflow.md。首次调姿对准固定目标；对合则依据当前机身 B 的观测和 CAD 相对装配关系计算；最终再调姿对全部测点使用一个共同变换。

三维下拉只切换模型显示，表格固定比较阶段实际/阶段观测/阶段目标。阶段 0 没有目标；插值时刻没有真实采样。只有正向播放；阶段按钮和滑条仍可自由选择查看时刻。橙色空心菱形表示目标点，始终绘制在模型和实际点上方；目标和实际点重合时也能辨认。阶段 0 勾选的是「首次调姿目标点」，作为下一阶段参照，表格仍不为初态编造目标。坐标轴显示 W 和各局部坐标系。右侧 R、t 是当前显示层的绝对位姿，不是运动增量。

## 故障选择

指定故障阶段和部件后，每条被选中注入故障的轨迹都使用该组合；正常轨迹仍不注入。

合法组合：首次调姿 1 可 A/B/C；前对合 2 仅 A；后对合 3 仅 C；再调姿 4 仅 ABC（整机）。不相容组合报错，不会悄悄替换。只指定部件时，随机阶段也只在合法阶段中采样，例如 B 只能在阶段 1 注入。

当前故障幅值是固定值，不是随机幅度：设置 2 mm，则每次额外平移偏差向量的长度都是 2 mm，方向随机。不同流程的初始摆放、工艺误差、测量误差也会不同。位置组合相同不代表样本只有一个量不同。

## 左侧其余参数

- 数据集名称：输出文件夹名称；重名不会覆盖。
- 随机种子：相同程序、参数和种子复现相同样本。
- 工艺平移 σ：每个活动刚体、每个世界轴的执行平移误差标准差，单位 mm。
- 测量噪声 σ：每个测点每个轴的读数误差标准差，单位 mm。它会通过反馈影响下一步运动。
- 全体故障比例：全部流程中被额外注入故障的比例。
- 故障幅值：固定的额外平移模长，方向随机，单位 mm。

σ 是波动尺度，不是最大误差。终检限度、健康样本数等算法专用配置已从生成参数移除。旧生成方式选择已删除，只保留当前 CAD 正向流程。

## CAD 参数

| 字段 | 含义 |
|---|---|
| radius | 主体半径，直径为其两倍 |
| nose_length / body_length / tail_length | 机头、机身、机尾主体长度 |
| exhaust_radius / exhaust_length | 出气筒外半径、伸出长度 |
| exhaust_offset | 每个出气筒中心离机体中心线的距离 |
| fin_span | 尾翼超出圆柱外侧的长度 |
| fin_root_chord / fin_tip_chord | 尾翼根部、外端的前后长度 |
| fin_sweep | 尾翼外端前缘向后偏移量 |
| fin_thickness | 尾翼厚度 |
| front_gap_mm / rear_gap_mm | 首次调姿后的前、后接口间隙 |
| initial_translation_mm | 初态各轴相对首次调姿目标原点的随机偏移上限 |
| initial_rotation_deg | 初态随机旋转角度上限 |
| process_rotation_deg | 每次执行时旋转向量各轴误差的标准差，单位度 |

长度单位 mm。尺寸决定几何；间距决定理想过程；初态范围决定开始多散、多歪；工艺误差决定执行精度。当前不计算接触或碰撞。

## 生成按钮与图

点击生成数据：检查参数 → 建模和定义目标 → 生成总数量的完整流程并随机分组 → 保存观测、真值、目标、R/t、标签 → 显示结果和已知装配结构图。

不会自动训练、健康校准、终检或运行溯源。当前新生成的图不高亮候选根因红线；灰线是状态延续，蓝线是定位到动作和动作到状态的关系。运行溯源后，红线严格绘制算法结果 trace_results.json 中的 path，不再将根因到终检点之间的所有可能路线都染红。当前算法定位根因后，在既定结构图中返回连接到终检点的路径。绿色边框和「真实根因」标记来自该样本的仿真注入标签，仅用于展示和评价，不参与预测。

## 独立因果溯源入口

进入“根因溯源”页，点击“载入数据集…”，选择已有数据目录；填写终检限度（默认 1 mm），点击“开始溯源”。它只读取已有数据，不重新生成数据。

当前方法需要健康参考，默认由训练标签中的正常流程提供。算法内部将这些正常训练流程按固定的 70/30 规则用于误差分布估计和阈值确定，每部分至少两条；不改变原数据 train/test，不额外生成 calibration 文件。测试标签只在预测完毕之后用于评价。真实坐标和执行矩阵不用于推断。

界面已删除健康参考输入。若缺少训练标签或正常训练样本不足四条，算法会说明原因，需要换用含足够正常训练样本的数据集；不会拿测试集或故障真值充当参考。

完成后，在同一页选择测试轨迹，下方因果图的红线立即联动。图按装配阶段从左到右排列，按机头、机身、机尾分带，支持横向和纵向滚动；总览中可查看候选排名。每次独立保存结果，生成数据按钮仍只负责生成。

## CAD 编辑窗口怎么用

1. 打开「CAD 尺寸、测点与目标…」。机头、机身、机尾各有独立页；尺寸输入旁附简要说明。三段共用接口半径，在机身页修改。
2. 改尺寸后点击「应用尺寸并刷新三段预览」。右侧显示 FreeCAD 实体网格和该段的局部原点、XYZ 轴。拖动旋转，滚轮缩放。
3. 单击模型表面，通过视线与 FreeCAD 实体精确求交选取当前可见表面上的点，将局部坐标填入 XYZ 输入框，同时在模型上以粉色十字显示「待确认点」。支持机头对接面内部、机身/机尾筒身和机尾装饰面；旋转模型后可选择另一侧。点击「新增」才加入列表。也可手动输入局部坐标并查看预览。
4. 从表格选择 checkpoint，修改 XYZ 后点击「修改选中」；点击「删除选中」移除该点，其余编号保持不变。新增编号取当前最大编号加一。
5. 点击「随机一个候选点」，仅生成一个粉色待确认点，操作与点击表面相同：可新增、修改选中的现有点，或取消候选点。是否选中了已有点都能使用随机；随机本身不改列表，不重编号。「取消候选点」保留已有测点。原先的随机点数和批量重选功能已删除。
6. 「阶段目标与初始工况」页设置前后间隙，以及最终 B 的 tX/tY/tZ 和绕 X/Y/Z 的旋转角。使用 R=Rz·Ry·Rx（列向量，先 X 再 Y 再 Z）组成合法旋转。上方模型可切换四个目标阶段并旋转/缩放观察，显示固定世界 W 和随目标移动的 A/B/C 局部坐标轴；下方可滚动查看 R、t。三段目标共同跟随 B 的最终方向和位置，对合间隙沿新的装配轴。初始范围与工艺误差另列解释。
7. 「校验并保存」检查每段至少 3 个不共线、无重复的点，并通过 FreeCAD 精确表面距离检查；失败时保留窗口供修改。取消不会改写主界面设置。成功保存仅影响下一次生成，已有数据集不变。

测点局部原点在各段主形体轴向中点；+X 指向机尾，Y 为横向、Z 为竖向。原点不在尖端、接口或装饰件中心。改尺寸不会自动移动已有测点，需要重新选点或恢复默认点。预览中的点和坐标轴透视标出，背面点也可见；点击表面则优先选当前可见面。

保存后的 checkpoint 在所有流程、所有阶段都固定于各自刚体。随机种子控制仿真，随机候选点使用连续三角面抽样，再投影到精确 CAD 表面，只有确认新增或修改才改变 CAD 测点配置。配准对测点等权，因此某段点更多时，该段对最终整机共同配准的权重也更大。


最终 B 位姿默认是 R=I、t=0，但现在可以设置为其他位姿。W 始终是外部固定基准，不会随着修改 B 的目标而移动。后对合与再调姿目标仍相同，最后再调姿的**理想增量**仍是单位变换；这不代表 B 的**绝对目标位姿**必须为单位变换。

「根因溯源」包含载入、运行、选择测试结果和横向因果图。独立坐标页已删除；三维装配页的坐标表保留。


## 显示开关与根因对照

所有显示开关使用统一图标：勾表示显示，空框表示隐藏，包括目标点、坐标系、初始状态与首次调姿。阶段 0 使用首次调姿目标作参照，阶段 1–4 显示对应阶段的目标点。

根因图红线对应算法返回的推断传播路径；绿色边框标记真实根因。若推断根因与真实根因相同，红色推断标记与绿色真实标记同时保留。没有注入故障时显示「无（未注入）」，缺失标签时显示「未知」，不会把预测结果当作真实根因。切换测试样本以及打开 SVG 时，两类标记都跟随当前选择。

真实标签单独保存在本次结果的 ground_truth.json，推断结果仍保存在 trace_results.json。改变测试标签不会改变算法分数、排名或推断路径。
